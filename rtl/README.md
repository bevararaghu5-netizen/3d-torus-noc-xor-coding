# RTL Source Modules

Author/maintainer: **B. Raghunadh**

This directory contains the Verilog HDL modules extracted from the project's supplied `codes.pdf` source material.

## Modules

| File | Purpose |
|---|---|
| `mesh_router_3d.v` | 3D Mesh router datapath/connectivity logic |
| `mesh_router_algo_3d.v` | Routing decision logic for the 3D Mesh reference design |
| `torus_router_3d.v` | 3D Torus router datapath/connectivity logic |
| `torus_router_algo_3d.v` | Routing decision logic for the 3D Torus design |

## Validation status

These files were transcribed from a PDF, so PDF line wrapping or formatting may have affected syntax. They have **not been independently verified by a clean Vivado compile in this repository**. Add the Vivado version, top module, constraints, and successful compile/simulation evidence after validating them in your local project.
